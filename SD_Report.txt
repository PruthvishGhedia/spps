1. INTRODUCTION
================================================================================

1.1 Project Overview
-------------------
The Student Performance Prediction System (SPPS) is a web-based application
designed to predict student academic performance and identify at-risk students
in educational institutions. The system analyzes various academic indicators
such as attendance, midterm scores, and previous grades to provide predictions
and early warnings for students who may struggle in their courses.

1.2 Purpose
----------
The purpose of this project is to develop a full-stack web application that
leverages machine learning algorithms to help educators identify struggling
students early in the semester, enabling timely intervention and support.

1.3 Scope
--------
The system includes:
- Student data management (CRUD operations)
- AI-powered performance prediction
- Data visualization and analytics
- CSV import/export functionality
- Real-time dashboard with statistics

================================================================================
2. PROBLEM STATEMENT AND OBJECTIVES
================================================================================

2.1 Problem Statement
---------------------
Educational institutions face challenges in early identification of students
who are at risk of academic failure. Traditional methods rely on reactive
approaches where intervention occurs only after students have already fallen
behind. There is a need for an automated, data-driven system that can:

- Store and manage student academic records efficiently
- Predict final examination scores based on current performance
- Classify students as "Safe" or "At Risk" for early intervention
- Provide visual analytics for administrators to make informed decisions

2.2 Objectives
-------------
1. To develop a user-friendly interface for managing student records
2. To implement an AI-based prediction model for academic performance
3. To provide real-time analytics and visualization of student data
4. To enable bulk data import and export functionality
5. To create a responsive and accessible web application

2.3 Expected Outcomes
--------------------
- A functional web application for student performance tracking
- AI-powered prediction engine with reasonable accuracy
- Interactive dashboard with charts and statistics
- CSV-based data import/export capability

5.2 Core Modules
---------------

5.2.1 Prediction Algorithm
The system uses a weighted algorithm combining Linear Regression and Decision
Tree logic:

WEIGHTED CALCULATION:
- Attendance:        20%
- Midterm 1 Score:   25%
- Midterm 2 Score:   35%
- Previous Grade:   20%

Total = (Attendance × 0.20) + (Midterm1 × 0.25) + (Midterm2 × 0.35) + (PrevGrade × 0.20)

CLASSIFICATION RULES (Decision Tree):
A student is classified as "At Risk" if ANY of the following conditions are met:
1. Predicted grade < 60%
2. Attendance < 75%
3. Midterm 2 dropped more than 15 points from Midterm 1

5.2.2 Key Code Implementation

Prediction Algorithm (geminiService.ts):
-------------------------------------------------
const W_ATTENDANCE = 0.2;
const W_MIDTERM_1 = 0.25;
const W_MIDTERM_2 = 0.35;
const W_PREVIOUS = 0.2;

const predictedGrade = Math.round(
  (student.attendance * W_ATTENDANCE) +
  (midterm1Normalized * W_MIDTERM_1) +
  (midterm2Normalized * W_MIDTERM_2) +
  (student.previous_grade * W_PREVIOUS)
);

if (predictedGrade < 60 || student.attendance < 75 || drop > 15) {
  status = "At Risk";
} else {
  status = "Safe";
}

-------------------------------------------------

5.3 Data Flow
-------------
1. User adds/imports student data
2. Data is sent to server via REST API
3. Server stores data in SQLite database
4. User clicks "Predict" button
5. Frontend calculates prediction using weighted algorithm
6. Prediction result is saved to database
7. UI updates to show predicted grade and status
