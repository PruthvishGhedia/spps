                             ABSTRACT
================================================================================

The Student Performance Prediction System (SPPS) is a web-based application
designed to predict student academic performance and identify at-risk students
in educational institutions. The system analyzes various academic indicators such
as attendance, midterm scores, and previous grades to provide predictions and
early warnings for students who may struggle in their courses.

The main objective of this project is to develop an automated system that can
help educators identify struggling students early in the semester, enabling timely
intervention and support. The system uses machine learning algorithms
including Linear Regression for grade prediction and Decision Tree logic for
student classification as "Safe" or "At Risk".

The application is built using React for frontend, Express.js for backend, and
SQLite for database management. It provides features including student data
management, AI-powered performance prediction, real-time analytics dashboard,
and CSV-based data import/export functionality.

This project demonstrates proficiency in full-stack web development and
showcases how modern web technologies can be applied to solve real-world
educational problems.

1.1 PROJECT SUMMARY

Project Name: Student Performance Prediction System (SPPS)

The Student Performance Prediction System is a web-based application designed
to automate the process of identifying students who are at risk of academic
failure. The main idea of the project is to maintain and handle all student data
including attendance, midterm scores, and previous semester grades, and use
this data to predict final examination performance.

The system analyzes various academic indicators to provide accurate predictions
of student performance. It classifies students as either "Safe" or "At Risk" based
on predefined criteria, enabling educators to take timely intervention measures.

Key features of the system include:
- Student data management with full CRUD operations
- AI-powered performance prediction using weighted algorithms
- Real-time analytics dashboard with statistics and charts
- CSV-based bulk data import and export functionality
- Responsive user interface with intuitive navigation
- Color-coded risk indicators for quick identification

The system addresses the need for early identification of at-risk students, which
is critical for improving overall academic outcomes and student success rates.



1.2 PURPOSE

The purpose of this project is to develop a web-based system that:
- Provides a centralized platform for managing student academic records
- Predicts student final examination scores based on current performance
- Identifies at-risk students early in the semester for timely intervention
- Offers visual analytics to help administrators make informed decisions
- Enables efficient data handling through CSV import/export features



1.3 SCOPE

In this system:
1. Administrator will be able to add, view, edit, and delete student records.
2. The system will predict final grades using AI algorithms.
3. Students will be classified as "Safe" or "At Risk" based on predictions.
4. The system will display real-time statistics and analytics.
5. Users will be able to import and export data in CSV format.

The system is designed for educational institutions, particularly for teachers and
administrators who need to monitor and predict student performance.



1.4 TECHNOLOGY REVIEW

Frontend: React 19.0.0

React is a JavaScript library for building user interfaces. It enables creating
reusable UI components and managing the view layer for web and mobile
applications. React uses a virtual DOM to optimize rendering and provides a
component-based architecture that makes code more predictable and easier to
debug.

React's key features include:
- Component-based architecture
- Virtual DOM for efficient updates
- One-way data binding
- JSX syntax for improved readability
- Rich ecosystem with numerous libraries

Backend: Express.js 4.21.2

Express.js is a minimal and flexible Node.js web application framework that
provides robust features for web and mobile applications. It provides a thin
layer of fundamental web application features without obscuring Node.js features.

Express.js key features include:
- Robust routing
- Middleware support
- Template engines
- Static file serving
- RESTful API creation

Database: SQLite (better-sqlite3 12.4.1)

SQLite is a lightweight, file-based relational database that does not require a
separate server process. The better-sqlite3 library provides a synchronous
interface for SQLite operations, making it ideal for small to medium-sized
applications.

SQLite key features include:
- Zero-configuration
- Single file storage
- ACID compliant
- Lightweight and fast
- No server required

Build Tool: Vite 6.2.0

Vite is a modern build tool that provides extremely fast hot module replacement
(HMR) and optimized production builds. It uses native ES modules and offers
instant server start.

Styling: Tailwind CSS 4.1.14

Tailwind CSS is a utility-first CSS framework that allows rapid UI development
by providing low-level utility classes. It enables building custom designs without
leaving the HTML.

Charts: Recharts 3.7.0

Recharts is a composable charting library built on React components. It provides
easy-to-use chart components for data visualization.

Language: TypeScript 5.8.2

TypeScript is a typed superset of JavaScript that compiles to plain JavaScript. It
provides static type checking, classes, interfaces, and modules for better code
organization and maintainability.

4.1 STUDY OF CURRENT SYSTEM

Currently, many educational institutions rely on manual methods to track student
performance. Teachers maintain spreadsheets or paper records to track student
attendance and grades. This manual approach has several drawbacks:

- Time-consuming data entry and retrieval
- Prone to human errors
- Difficult to identify at-risk students early
- No automated analysis or prediction capabilities
- Limited visualization and reporting options

The proposed system addresses these issues by providing an automated,
centralized platform for student performance management and prediction.



4.2 PROBLEMS & WEAKNESS OF CURRENT SYSTEM

- Manual data entry is time-consuming
- High chance of human errors in calculations
- No automated prediction mechanism
- Difficult to identify at-risk students early
- Limited data visualization capabilities
- No bulk data handling capability
- No centralized database management



4.3 REQUIREMENT OF NEW SYSTEM

Functional Requirements:
- FR01: Add new student with details (name, attendance, midterms, previous grade)
- FR02: View list of all students
- FR03: Edit existing student records
- FR04: Delete individual or all student records
- FR05: Import bulk data via CSV
- FR06: Export data to CSV
- FR07: Predict final grades for students
- FR08: Classify students as Safe or At Risk
- FR09: Display statistics (total, at-risk, safe, average attendance)
